## 2. Calculation Formula Sanity

- `effective_exposure = leverage * size_multiplier`.
- Per-entry notional uses the V0 baseline risk-sized notional ratio scaled by effective exposure: `new_notional = sizing_equity * baseline_notional_ratio * effective_exposure`.
- Margin used is estimated as `gross_notional / exchange_leverage`; the same effective exposure can therefore have different margin usage when exchange leverage differs.
- Fee basis is notional, applied at entry, partial exits, and final exits using the scenario fee rate.
- Slippage basis is notional through execution prices already generated by the V0 engine for each slippage scenario.
- PnL scales with position units, which scale with effective exposure. Compounding is path-dependent because later notional uses current sizing equity.
- Equity curve uses hourly mark-to-market equity on 1,000 USD initial capital.
- Liquidation estimate uses `entry_price * (1 - 1 / leverage + maintenance_margin + liquidation_fee_buffer)`. 1x has no liquidation price.
- Liquidation touch checks whether 1h lows during holding touched the estimated liquidation price; gap touch checks 1h opens.
- Cost stress is implemented by rerunning the V0 entries/exits under fee/slippage multipliers: base, cost 2x, slippage 2x, cost 2x + slippage 2x, and cost 3x + slippage 3x.

## 5. Risk Policy Draft

| item | proposal | reason |
|---|---|---|
| max_exchange_leverage | 3x for paper; 1x live default; 5x prohibited | 3x size 25% is the highest PASS futures paper candidate; 5x has liquidation touch. |
| max_effective_exposure | <= 1.0x hard cap | 1.5x+ fails MDD/cost-stress screens; 1.0x is WATCH under cost stress. |
| max_position_size_multiplier | 50% at 2x, 25% at 3x/4x, 0% at 5x | Keeps effective exposure at or below 1.0x and avoids liquidation-touch 5x cases. |

| max_daily_loss | -3% reduce-only, -5% pause | Keeps daily loss below worst-month accumulation speed. |
| max_weekly_loss | -7% reduce-only, -10% pause | Limits clustered stop/funding stress before monthly threshold is reached. |
| max_monthly_loss | -12% reduce-only, -15% pause/committee review | Below V0 worst cost-stress drawdown regime and near practical tolerance. |
| max_open_positions | 3 | Matches V0 baseline engine assumption. |
